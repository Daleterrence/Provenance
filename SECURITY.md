# Security

If you've found a security problem in Provenance, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/Daleterrence/Provenance/security/advisories/new) instead of opening
an issue.

Say what you found, how to make it happen, and which version you're on (it's at the bottom of the General page in Settings). I'll get back to
you as soon as I can.

Fixes go into the latest release, so that's the only version that's supported.
